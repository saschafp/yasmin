# YASMIN

**Yet Another Stencil Mini Intermediate Notation**

Yasmin is a small Python package for experimenting with stencil comutations and backend-independent intermediate representations.

The project is part of the [High Performance Computing for Weather and Climate](https://www.vvz.ethz.ch/Vorlesungsverzeichnis/lerneinheit.view?lerneinheitId=199803&semkez=2026S&lang=en&ansicht=ALLE) course at ETH Zurich.
